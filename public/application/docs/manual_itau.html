Manual Itau PIX no Gestor de Locações

Use este guia para preparar o certificado dinamico do Itau e preencher a integracao no Gestor de Locações.

1. O que voce precisa pedir ao Itau

  1. Ter o produto/API PIX contratado no Itau.
  2. Pedir ao gerente, ponto focal, OfficerCash ou API Owner as credenciais de producao para PIX.
  3. Receber o Client ID e o token temporario. Esse token tem prazo curto; gere o certificado logo depois.

2. Gerar o certificado dinamico

  1. Acesse o Portal Itau for Developers e faca login com um usuario administrador.
  2. Entre em gestao de certificados e clique em gerar certificado.
  3. Informe um nome para o certificado, o Client ID, site/app da empresa, pais, estado, cidade e o token da credencial.
  4. Baixe e guarde os arquivos retornados: certificado .crt, chave privada .key e o Client Secret.
Importante: o certificado e a chave privada sao segredos. Nao envie por WhatsApp, nao coloque no GitHub e nao deixe em pasta publica do site.

3. Gerar manualmente com OpenSSL, se o portal pedir CSR

Se voce precisar gerar um CSR manual, o campo CN precisa ser exatamente igual ao seu Client ID.

openssl genrsa -out itau-key.key 2048
openssl req -new -key itau-key.key -out itau-request.csr -subj "/CN=SEU_CLIENT_ID/OU=RENTAL/L=SuaCidade/ST=SeuEstado/C=BR"

Depois envie o conteudo do arquivo itau-request.csr ao endpoint de solicitacao de certificado do Itau com o token temporario. O retorno traz o Client Secret e o certificado .crt.

4. Configurar no Gestor de Locações

  1. Abra Integrações de pagamento e selecione Itau.
  2. Deixe em demo ate ter tudo pronto.
  3. Preencha Client ID, Client Secret, Chave PIX, URL Token OAuth, URL Base API PIX, caminho do certificado .crt e caminho da chave .key.
  4. Clique em Salvar Itau.
  5. Depois clique em Testar conexao. Se o teste passar, selecione Itau em "Usar para gerar PIX".

5. URLs padrao

Token OAuth:

https://sts.itau.com.br/api/oauth/token

Base PIX configuravel no Gestor de Locações:

https://secure.api.itau/pix_recebimentos/v2

Confirme a URL exata no produto contratado no portal do Itau, porque ela pode variar por API.

6. Erros comuns

  • C100/C200: certificado ausente ou invalido. Confira o caminho do .crt.
  • C600/C800a: CN diferente do Client ID. Gere outro CSR/certificado.
  • 403: token expirado, certificado errado, Client Secret incorreto ou URL da API errada.
  • Token vencido: normal. O Gestor de Locações renova automaticamente; o token do Itau dura poucos minutos.

Documentacao oficial: certificado dinamico, autenticacao mTLS e primeira chamada a API.
